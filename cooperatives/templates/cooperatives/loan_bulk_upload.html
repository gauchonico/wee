CSV Format Instructions

Your CSV file should include the following columns:

  • member_id - The member ID of the member
  • request_date - Date of the loan request (YYYY-MM-DD)
  • amount_requested - Amount requested by the member
  • amount_approved - Amount approved (can be empty)
  • agent_id - ID of the agent processing the request
  • status - Status of the loan (pending, approved, or rejected)
  • date_of_birth - Member's date of birth (YYYY-MM-DD)
Example CSV:
member_id,request_date,amount_requested,amount_approved,agent_id,status,date_of_birth
123,2024-03-20,1000,1000,1,approved,1990-01-01
124,2024-03-20,2000,,1,pending,1991-02-02
