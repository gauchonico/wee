Upload a CSV file with the following columns:

  • member_id - The ID of the member to update
  • cooperative - (Optional) The name of the cooperative
  • farmer_group - (Optional) The name of the farmer group
  • products - (Optional) Comma-separated list of product names
  • land_acreage - (Optional) Total land acreage
  • shea_trees - (Optional) Number of shea trees
  • sunflower_acreage - (Optional) Acreage for sunflower planting

For sunflower acreage, a new planting allocation will be created with:

  • Planting date set to today
  • Harvest date set to one year from planting
  • Status set to 'planted'
