Instructions:

Upload a CSV file with the following columns:

  • name - Name of the farmer group (required)
  • code - Unique code for the farmer group (optional, will be auto-generated if not provided)
  • cooperative - Name of the cooperative (required)
  • district - Name of the district (required)
  • subcounty - Name of the sub-county (required)
  • parish - Name of the parish (optional)
  • village - Name of the village (optional)
  • phone_number - Phone number of the contact person (optional)
  • is_vsla - Whether the group is a VSLA (true/false) (optional)

Note:

  • The cooperative, district, and sub-county must already exist in the system
  • Column names are case-sensitive
  • For is_vsla, use 'true' or 'false' (case-insensitive)
